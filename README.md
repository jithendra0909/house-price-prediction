# House Price Prediction using Machine Learning

## About the Project
A beginner-level supervised machine learning project that predicts California house values using the California Housing dataset and Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Machine Learning Workflow
1. Dataset loading
2. Data inspection and exploration
3. Feature and target separation
4. Training and testing split (80:20)
5. Linear Regression model training
6. Prediction generation
7. Model evaluation

## Model Evaluation
| Metric | Result |
|---|---:|
| MAE | 0.5332 |
| MSE | 0.5559 |
| R² Score | 0.5758 |

## Dataset
California Housing dataset from Scikit-learn.

## Learning Outcome
Gained practical experience with the fundamental supervised machine learning workflow.
